AI Generation Settings

Your API key is stored only in this browser (localStorage) and sent directly from your browser to Anthropic's API. It is never sent anywhere else.

If AI generation fails with a network/CORS error, try running this file from a local server instead of opening it directly: python3 -m http.server in this folder, then visit http://localhost:8000/p5_practice_app.html.

Parent PIN

With a PIN set, the app opens in child mode: only To-Do, Practice and Progress are shown, answers stay hidden until a paper is submitted, and only a parent can mark written answers. Tap "Parent mode" in the header and enter the PIN to unlock everything.

Data

Everything (question bank, generated papers, progress) is stored locally in this browser. Export a backup, or clear everything to start over.
